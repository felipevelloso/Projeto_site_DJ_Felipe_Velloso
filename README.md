🌐 Projeto de Conclusão — Desenvolvimento Web
📌 Sobre o projeto

Este projeto foi desenvolvido como Projeto de Conclusão do Curso de JavaScript no SENAI Anchieta, sob orientação da professora Natália.

Durante o curso, tivemos a oportunidade de construir um projeto de forma colaborativa, utilizando-o como base prática para aprender e aplicar os principais conceitos de HTML, CSS e JavaScript no desenvolvimento de páginas web.

Mais do que apenas concluir uma atividade acadêmica, este projeto representa uma etapa importante da minha jornada de transição e desenvolvimento na área de tecnologia.

🚀 Tecnologias e conhecimentos aplicados

Durante o desenvolvimento do projeto, pude colocar em prática conhecimentos relacionados a:

HTML5 — estruturação e organização das páginas;
CSS3 — estilização, layout e apresentação visual;
JavaScript — lógica, interatividade e comportamento da aplicação;
Desenvolvimento de páginas Web — organização e construção de interfaces;
Git e GitHub — versionamento e publicação do projeto;
Node.js — introdução aos conceitos de desenvolvimento no lado do servidor.

O conteúdo relacionado ao Node.js ainda está em fase inicial para mim, mas faz parte dos conhecimentos que pretendo aprofundar e aplicar progressivamente nos meus próximos projetos.

🎯 O que este projeto representa

Este projeto representa a aplicação prática dos fundamentos que venho construindo na minha formação como desenvolvedor.

Ao longo do curso, fui incentivado pela professora Natália a não enxergar o projeto apenas como uma entrega acadêmica, mas também como uma oportunidade para começar a construir meu portfólio profissional.

Essa orientação foi muito importante para mim, pois entendi que desenvolver projetos, documentá-los e compartilhá-los faz parte da construção da minha trajetória e da minha autoridade como profissional de tecnologia.
